# Продолжай своё оффлайн-путешествие

Небольшой патч сообщества для **Last Epoch 1.5.1**. Исправляет инициализацию оффлайн-профиля и обработку пустого кэша косметического магазина: возвращает работу городских телепортов, устраняет проблему наград сезонного энкаунтера и помогает применять и сохранять косметику, включая эффекты навыков.

**Предварительный релиз:** поддерживается одна проверенная сборка Windows. Полное прохождение сезонного боя ещё требует дополнительной проверки. Подробнее — в [таблице совместимости и проверок](docs/compatibility.md).

## Что исправлено

| Проблема | Что меняется |
| :--- | :--- |
| **Телепорт не работает** через клавишу **T** и кнопку интерфейса | Создаётся корректный оффлайн-профиль, используемый для создания и привязки портала. |
| **Bloodrage Crystals — 5/5**, а в окне наград **0** | Исправляется профиль, используемый для участия в сезонном событии и начисления наград. |
| **Скины не надеваются или сбрасываются**, эффекты навыков не выбираются | Заполняются поля профиля для сохранения выбора и обрабатывается незагруженный список наборов магазина. |

Установщик меняет **GameAssembly.dll** и сохраняет проверенную копию оригинала. Сохранения персонажей не редактируются. Патч затрагивает путь оффлайн-входа и предназначен для **Play Offline**.

## Установка в четыре шага

1. **[Скачай ZIP](https://github.com/aleks10sadu-ops/last-epoch-offline-fixes/archive/refs/heads/main.zip)** и распакуй папку целиком.
2. **Полностью закрой Last Epoch.** Перед установкой предварительного мода отдельно сохрани копию файлов персонажей.
3. Открой **`Install.cmd`** двойным щелчком и выбери **`Last Epoch.exe`** в папке игры. Дождись зелёной надписи “Installed”.
4. Запусти игру обычным способом и выбери **Play Offline**.

**Основному установщику не нужны Python, загрузчик модов, вход в аккаунт или права администратора.** Папка игры должна быть доступна для записи. Оригинальный DLL сохраняется в `ПАПКА_ИГРЫ\.le-offline-fixes\GameAssembly.original.dll`.

<details>
<summary><b>Установка через PowerShell и проверка совместимости</b></summary>

Открой PowerShell в распакованной папке. Замени путь в примере своим:

```powershell
.\Install.ps1 -GameDirectory "D:\Games\Last Epoch" -Check
.\Install.ps1 -GameDirectory "D:\Games\Last Epoch"
```

`-Check` только читает DLL и показывает хеш и статус. Неподдерживаемый файл не изменяется. `Install.cmd` задаёт политику выполнения только для своего процесса Windows PowerShell; сохранённые настройки системы остаются прежними.

</details>

### Совместимость с точной сборкой

Версия **1.5.1**, сборка **25672295**, Windows x64. SHA-256 оригинального `GameAssembly.dll`:

```text
502E32F1F31BC1979AC6C387FAEF1266A62AD29F5B573E6D9B51CB577A72F5F8
```

Одного номера версии недостаточно: хотфикс, другая платформа или изменённый DLL могут содержать другой код. Принудительной установки нет. Для других сборок нужен отдельно подготовленный и проверенный патч.

## Косметика

После установки открой **Appearance** (`Shift+K` или вкладка Appearance в инвентаре). Выбери слот экипировки либо косметический слот под навыком нужного класса, примени внешний вид и перезапусти игру, чтобы проверить сохранение выбора.

**Твоя косметика остаётся твоей.** Патч сохраняет штатные проверки владения и фильтрацию списка. Он не добавляет идентификаторы косметики, не разблокирует DLC и наборы поддержки, не подменяет кэш доступных предметов и не меняет Epoch Points. Исправляется применение и сохранение косметики, которая уже доступна твоему аккаунту в локальном кэше игры.

Для полностью оффлайн-игры этот кэш нужен. Если купленная косметика из DLC или наборов поддержки отсутствует, войди в аккаунт владельца и открой Appearance при подключении, дай игре сохранить список, затем вернись в Play Offline. Подробнее — в [официальной инструкции EHG](https://support.lastepoch.com/hc/en-us/articles/48418105189659-How-do-I-equip-cosmetics-I-ve-purchased-unlocked-in-Last-Epoch). Само наличие файла ресурса не подтверждает покупку. Патч не может восстановить покупки, которые ещё не попали в кэш.

## Как откатить

Закрой игру, открой **`Restore.cmd`** и выбери тот же исполняемый файл. Восстановится проверенный оригинальный DLL; текущий прогресс персонажей и косметический кэш сохранятся.

```powershell
.\Restore.ps1 -GameDirectory "D:\Games\Last Epoch"
```

Перед обновлением игры выполни откат. Если резервная копия потеряна, восстанови игровые файлы через проверку в своём лаунчере. Не устанавливай патч на новый DLL, пока его хеш явно не поддерживается.

## Если что-то не работает

| Сообщение или симптом | Что сделать |
| :--- | :--- |
| **Unsupported DLL** | Проверь сборку и хеш. Верни оригинальный DLL вместо других модификаций либо используй подходящую установку игры. |
| **Close Last Epoch** | Полностью выйди из игры и повтори установку. |
| **Access denied** | Проверь права записи в папку игры и распакованный каталог. |
| **Already installed** | Хеш совпадает с патчем; файлы не изменены. |
| **Купленная косметика отсутствует** | Войди в аккаунт владельца и подготовь официальный оффлайн-кэш. Патч не добавляет покупки, которых нет в кэше. |
| **Сезонные награды всё ещё зависли** | Перейди в новую боевую локацию и проверь новое событие. Установщик не переписывает уже созданные предложения наград. Пришли результат со сборкой и хешем DLL. |

## Помоги проекту

Если исправление помогло — **поставь звезду репозиторию**. Отчёты других игроков помогают проверить больше игровых сценариев.

Оформи [сообщение об ошибке](https://github.com/aleks10sadu-ops/last-epoch-offline-fixes/issues/new?template=bug_report.yml): укажи сборку, хеш DLL, способ оффлайн-запуска и шаги воспроизведения. Публикуй только нужный фрагмент журнала, удалив личные данные. Сохранения персонажей и сведения аккаунта оставь у себя. Правила участия — в [CONTRIBUTING.md](CONTRIBUTING.md).
